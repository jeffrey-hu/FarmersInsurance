On September 15, 2026 the First Set was rebuilt from 34 requests to 63 under `RFA_First_Set_Independent_Review_2026-09-15.md`. Requests were split, corrected, reordered, added, dropped, and moved to a Second Set.

**Everything in `Proposed_Changes_RFA_First_Set_2026-09-12.md` — items A-1 through A-14 — is numbered against the 34-request draft.** Applying any of them against the operative set without this map lands the change on the wrong request. Item **A-13**, for example, corrects "RFA 18," which was the compound downspout request; in the operative set No. 18 is the award's "F1.7"/"B1.2" designation and the downspout requests are 42–46.

Read with `../../Document_Formatting_Standard.md` § 7: **renumbering is safe only before service.** Neither set has been served, so the operative numbering can still change. Once it is served the numbers are fixed — withdraw by letter and leave the gap, never renumber.

Serve it alongside **new 20** — that the award states no value or loss for any window other than F1.7 and B1.2 — so the pair reads: binding as to what it determined, and it determined only two windows.

## Why the older draft is retained rather than deleted

`[Superseded 2026-09-12] …docx` is kept as a dated baseline because the pending proposals in `Proposed_Changes_RFA_First_Set_2026-09-12.md` are numbered against **its** request numbers, not the operative set's. Items A-1 to A-14 cannot be read without it. The bracketed prefix follows `../Document_Formatting_Standard.md` § 8: a dated baseline is labeled so it can never be mistaken for the version to serve.

✅ **The renumbering is mapped** — `FirstSet/RFA_Renumbering_Map_2026-09-15.md`. It carries old 1–34 → new 1–63, the 21 new-origin requests, and every A-item scored against the operative set with a revised number. **Read it before applying any A-item.** `../Document_Formatting_Standard.md` § 7 also applies: once the First Set is served, its numbers are fixed — withdraw by letter and leave the gap, never renumber.
